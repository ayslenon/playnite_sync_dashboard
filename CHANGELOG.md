# Changelog — Dashboard

## 1.3.0 — 2026-08-16

- Corrigido o badge de playtime vazio quando o valor formatado é `null`.
- O contador de jogos “A Testar” agora considera a marcação independentemente do armazenamento.
- Adicionado suporte PWA com manifest, service worker e ícones instaláveis.
- Substituídos os ícones padrão do Vite por um gamepad opaco em azul-marinho/roxo, incluindo o asset específico de 180px do iOS.
- Simplificado o desenho do gamepad usando a geometria local do ícone `Gamepad2` do Lucide.
- A API passou a ser resolvida pela origem HTTPS atual, com compatibilidade para capas relativas do Playnite.
- Documentação atualizada para HTTPS local, hostname mDNS, dual boot e comportamento offline do shell.

## 1.2.1

- Padronização da origem da API na rede local e compatibilidade com capas antigas.
- Ajustes de filtros, playtime e busca HLTB.

## 1.2.0
